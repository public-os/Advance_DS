# Advance_Data_Structure
1. Counting Sort
<br>
Time Complexity:
<br>
Best Case: O(n + k)
<br>
Average Case: O(n + k)
<br>
Worst Case: O(n + k)
<br>
where:
<br>
n = number of elements
<br>
k = range of input values (max − min)
<br>
Space Complexity:
<br>
O(n + k)

3. Radix Sort
Time Complexity:
Best Case: O(nk)
Average Case: O(nk)
Worst Case: O(nk)
where:
n = number of elements
k = number of digits (or passes)
Space Complexity:
O(n + k) (depends on internal stable sort like counting sort)

4. Bucket Sort
Time Complexity:
Best Case: O(n + k)
Average Case: O(n + k)
Worst Case: O(n²)
Worst case happens when all elements go into the same bucket
Space Complexity:
O(n + k)
